# Prathith Rao Portfolio

A static portfolio built with HTML, CSS and JavaScript. Open `index.html` directly to preview the site. Project content is in `index.html`, styling is in `style.css`, and animation and filtering are in `script.js`.

For the account-level Pages URL, place these files at the root of the public `Prathith-Rao/prathith-rao.github.io` repository. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**.

The site’s custom dot-matrix artwork uses Canvas and CSS. It uses Space Grotesk and IBM Plex Mono from Google Fonts with local system fallbacks. The motion control pauses both the hero artwork and the typewriter effect, and animation starts paused when the visitor requests reduced motion.
